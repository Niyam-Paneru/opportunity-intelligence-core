# Invariants

1. **Hard ineligibility is not a score penalty; it is rejection.**
2. **Duplicate identity is deterministic and inspectable.**
3. **Every score contribution has a named reason.**
4. **The score is never presented as probability of sale.**
5. **Higher priority can create a proof plan, not automatic outreach.**
6. **Human review remains the final boundary before contact.**
7. **Unsupported confidence is not invented to fill a blank.**

The system ranks attention. It does not predict destiny.
